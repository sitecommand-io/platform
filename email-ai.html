Connect Your Email
Your AI reads every email, flags the important ones, and drafts replies — so you only deal with what matters. Setup takes 3 minutes.
Which email do you use?
1
Go to Google Cloud Console
You need to create a free Google Cloud project to get your API credentials. This is a one-time setup that takes about 3 minutes.
🔗 Open this link in a new tab:
console.cloud.google.com →
Steps:
1. Sign in with your Google account
2. Click Select a project → New Project
3. Name it SiteCommand Email
4. Click Create
2
Enable the Gmail API
Tell Google you want to use Gmail in your app.
🔗 Click this link (opens in your project):
Enable Gmail API →
Click the blue Enable button on that page.
3
Create OAuth Credentials
This gives your app permission to read your emails.
1. Go to APIs & Services → Credentials
2. Click + Create Credentials → OAuth client ID
3. If asked to configure consent screen: click Configure
   • User type: External → Create
   • App name: My Email AI
   • Your email for support and developer contact
   • Click Save → Save → Back to Dashboard
4. Back to Credentials → + Create Credentials → OAuth client ID
5. Application type: Web application
6. Name: Email AI
7. Authorized JavaScript origins → Add: https://sitecommand-io.github.io
8. Click Create
4
Paste Your Client ID
Copy the Client ID from the popup Google shows you. It looks like: 123456789-abc.apps.googleusercontent.com

🔒 Your Client ID is stored only in your browser. We never see it.
